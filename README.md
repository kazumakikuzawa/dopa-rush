# RUSH//CORE

CHARGEを増幅し、8段階のPHASE、8つのSignal Node、MOD、実績、ASCENSIONを進める依存なしのブラウザ向けインクリメンタルゲームです。

## Development

```sh
npm install
npm run dev
```

品質確認は `npm run format:check && npm run type-check && npm run lint && npm test && npm run build && npm run test:e2e` で実行できます。

公開版: https://kazumakikuzawa.github.io/dopa-rush/
